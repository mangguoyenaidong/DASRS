# DASRS 项目介绍

我的作品名称是 DASRS 分布式安全检测与响应平台。它来源于对当前网络空间安全形势和实际防护需求的持续关注。

在数字化环境不断扩展的今天，网络攻击已经从单点试探逐渐演变为自动化、持续化、规模化的攻击活动。无论是面向企业服务器的漏洞利用、面向业务系统的恶意探测，还是针对公网资产的批量扫描与入侵尝试，都说明传统依赖人工研判和被动处置的安全防护方式已经越来越难以满足现实需求。尤其是在攻击面不断扩大、告警数量持续增长的情况下，如何实现对安全事件的持续发现、快速分析与及时响应，已经成为网络安全建设中的关键问题。

基于这样的背景，我设计并实现了 DASRS 分布式安全检测与响应平台。该平台围绕“持续监测、智能研判、协同响应”的思路构建，能够对网络环境中的安全告警进行采集、分析、评分和处置，并结合 AI 能力提升攻击情报分析深度和处置辅助能力，从而增强平台对真实威胁的发现能力和响应能力。

本作品主要包括以下几个部分：

一是 Agent 节点采集单元。该单元部署在被监测主机或网络节点侧，负责采集 Suricata 产生的安全告警日志，同时获取本地服务与资产信息，并将相关数据实时上报给中心端。它相当于整个平台的前端感知层，承担告警接入、节点状态同步和本地执行等任务。

二是 Master 中心分析与调度单元。该单元是平台的核心控制中心，负责接收各个 Agent 上报的告警和资产信息，对告警进行统一存储、风险评分和策略判断，并根据分析结果向在线 Agent 下发阻断、解封、测试、部署等指令，实现检测与响应的联动闭环。

三是 风险评估与策略处置单元。平台并不是简单地对告警做静态展示，而是结合告警等级、目标资产服务信息、时间窗口内的频次变化以及白名单状态等因素，对告警进行综合评分，进而辅助判断是忽略、告警关注，还是执行封禁、修复等动作。这样可以在一定程度上降低误报影响，提高处置决策的针对性。

四是 Web 可视化管理单元。平台提供统一的 Web 控制台，用于展示资产信息、告警信息、封禁状态、策略配置、运行日志以及 AI 工作流等内容，便于运维人员和安全人员从可视化界面对整个平台进行统一管理、人工复核和操作控制。

五是 AI 智能情报分析单元。为了进一步提高平台的工作效率和威胁研判能力，系统引入了 AI 相关能力。平台能够结合 Agent 侧扫描到的资产信息、开放服务、节点指纹以及当前产生的攻击告警，对攻击行为进行上下文关联分析，识别其是否与真实暴露面、实际业务服务和关键资产高度相关，从而将攻击区分为普通攻击与更具针对性、有效性的攻击。通过这种方式，平台不仅能够输出攻击类型、风险原因、影响范围、可疑参数、操作建议和推荐动作等内容，还能够提升安全人员的研判速率，增强安全告警向高价值安全情报转化的能力。

在技术实现上，本作品采用了 Master-Agent 分布式架构，结合 Suricata 告警采集、gRPC 通信、Web 管理后台、MySQL/Redis 数据支撑以及 AI 模型能力接入等技术手段。其中，AI 部分重点吸收了当前大模型和智能体技术在安全场景中的发展思路。近年来，AI 技术已经从早期的问答与文本生成，逐步发展到能够完成多步骤分析、上下文理解和决策支持的智能化阶段。在本平台中，AI 的主要作用并不是替代人工，而是作为安全分析助手，结合资产扫描结果和攻击告警上下文，对攻击行为进行有效性判断、信息提炼和处置建议输出，从而提升平台的自动化程度、研判效率和情报价值。

目前，本作品已经完成了整体框架的搭建，形成了从告警采集、中心分析、评分决策到联动响应、可视化展示的基本闭环。同时，基于资产信息的 AI 攻击情报分析功能已经进入联调和测试阶段，平台已经具备较强的扩展能力和应用潜力。后续将继续围绕误报抑制、资产识别增强、攻击有效性分类和 AI 能力稳定性等方面进行完善，逐步推动平台走向更加成熟和实用的在线测试与应用阶段。
